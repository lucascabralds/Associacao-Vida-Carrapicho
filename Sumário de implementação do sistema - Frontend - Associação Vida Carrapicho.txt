# 1. 🌻 Visão Geral do Sistema

O sistema da **Associação Vida Carrapicho** é uma plataforma web completa desenvolvida para auxiliar a ONG na divulgação institucional, gerenciamento administrativo, controle financeiro e organização de eventos.

O projeto foi dividido em dois grandes módulos:

---

## 🌐 Site Institucional (Frontend Público)

Landing Page responsiva e interativa desenvolvida para:

- Apresentar a ONG e sua missão
- Divulgar eventos e ações sociais
- Facilitar doações via PIX
- Exibir transparência financeira
- Captar voluntários e parceiros

O frontend possui:

- Navegação fluida
- Design responsivo
- Animações modernas
- Modais interativos
- Sistema de eventos dinâmicos
- Geração automática de QR Code PIX

---

## 🔐 Painel Administrativo (Sistema Restrito)

Sistema completo de gerenciamento interno com autenticação JWT.

Permite:

- CRUD de eventos
- Upload de imagens
- Gestão financeira
- Gestão de voluntários
- Controle de usuários
- Dashboard estatístico
- Relatórios PDF

---

## 🎯 Objetivos do Projeto

- Modernizar a presença digital da associação
- Facilitar arrecadações via PIX
- Garantir transparência financeira
- Melhorar organização administrativa
- Automatizar processos internos
- Disponibilizar acesso responsivo em qualquer dispositivo

# 7. 🔧 Configuração de Dependências e APIs

# 🗄️ Banco de Dados PostgreSQL

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(20) DEFAULT 'editor',
    active BOOLEAN DEFAULT true,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE events (
    id SERIAL PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    description TEXT,
    event_date TIMESTAMP NOT NULL,
    location VARCHAR(200),
    status VARCHAR(20) DEFAULT 'upcoming',
    created_by INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE event_images (
    id SERIAL PRIMARY KEY,
    event_id INTEGER REFERENCES events(id) ON DELETE CASCADE,
    image_url VARCHAR(500),
    is_cover BOOLEAN DEFAULT false
);

CREATE TABLE transparency (
    id SERIAL PRIMARY KEY,
    type VARCHAR(20),
    category VARCHAR(50),
    description TEXT,
    amount DECIMAL(10,2),
    transaction_date DATE
);

CREATE TABLE donations (
    id SERIAL PRIMARY KEY,
    donor_name VARCHAR(100),
    donor_email VARCHAR(100),
    amount DECIMAL(10,2),
    pix_payload TEXT,
    qr_code TEXT,
    status VARCHAR(20)
);

CREATE TABLE voluntarios (
    id SERIAL PRIMARY KEY,
    nome VARCHAR(100),
    email VARCHAR(100),
    telefone VARCHAR(20),
    disponibilidade TEXT,
    interesse TEXT,
    status VARCHAR(20)
);

CREATE TABLE contacts (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100),
    phone VARCHAR(20),
    message TEXT
);
```

# 11. 🛠️ Solução de Problemas

| Problema             | Solução                    |
| -------------------- | -------------------------- |
| Gráfico não aparece  | Verifique internet/CDN     |
| QR Code falha        | Use PIX Copia e Cola       |
| Admin não abre       | Execute `npm start`        |
| Login inválido       | Verifique PostgreSQL       |
| Upload falha         | Verifique pasta uploads    |
| Eventos não carregam | Confirme API na porta 3000 |
